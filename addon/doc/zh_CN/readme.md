# NVDA 的 WithSounds 插件

**用耳标（Earcons）增强你的 NVDA 使用体验！**

## 概述

WithSounds 是一款简单的 NVDA 插件，通过用直观的耳标（简短、独特的声音）替换某些语音反馈，来增强你的浏览和计算机交互体验。目前，WithSounds 主要为网页链接提供听觉提示，目标是减少冗长提示，让体验更高效。

## 功能

* **链接角色：** 在浏览模式下，将 NVDA 对角色为“链接”的语音反馈替换为耳标。诸如“链接 首页”、“链接  NVDA 中文站”这样的反馈，其中的“链接”会变成一段简短、悦耳的声音。这可以显著减少语音干扰且不丢失信息，尤其是在包含大量链接的网页上。
* **已访问状态：** WithSounds 会将已访问的链接替换为另一个耳标，从而使网页导航更高效。

## 重要说明

1. **功能简单：** 这是一个非常基础的插件。Tony 的 “Earcons and speech rules” 插件提供了类似功能，但特性和配置选项更丰富。WithSounds 可以看作是一个更简化的替代方案，专注于“链接”和“已访问”状态。
2. **避免冲突：** 建议你**不要同时安装 WithSounds 和 Tony 的 “Earcons and speech rules” 插件**。同时安装可能会导致行为异常或功能冲突。
