# WithSounds for NVDA

**Enhance your NVDA experience with earcons!**

## Overview

WithSounds is a simple NVDA add-on that improves browsing and computer interaction by replacing some speech feedback with intuitive earcons, which are short, distinctive sounds. Currently, WithSounds focuses on auditory cues for web links, helping reduce verbosity and make navigation more efficient.

## Features

* **Link role:** In browse mode, WithSounds replaces NVDA's spoken indication of the "link" role with an earcon. For example, when NVDA would normally say "link Home" or "link NVDA Chinese website", the word "link" is replaced with a short, pleasant sound. This significantly reduces speech clutter without losing information, especially on web pages containing many links.
* **Visited state:** WithSounds uses a different earcon for visited links, making web navigation more efficient.

## Important Notes

1. **Simple functionality:** This is a very basic add-on. Tony's [Earcons and speech rules](https://github.com/mltony/nvda-phonetic-punctuation/) add-on provides similar functionality, but with more features and configuration options. WithSounds can be seen as a simpler alternative focused on the link role and visited state.
2. **Avoid conflicts:** It is recommended that you **do not install WithSounds alongside Tony's "Earcons and speech rules" add-on**. Installing both may cause unexpected behavior or feature conflicts.
